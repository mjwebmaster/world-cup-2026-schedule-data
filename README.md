# World Cup 2026 Schedule Data

Free World Cup 2026 schedule data in JSON, CSV and ICS formats.

This repository provides structured World Cup 2026 match schedule data for developers, bloggers, sports websites, calendar tools, spreadsheet users, and fans.

Maintained by [WorldCup2026Schedules.com](https://worldcup2026schedules.com/).

> Independent fan guide. Not affiliated with FIFA.

## Available files

| File | Format | Best for |
|---|---:|---|
| `world-cup-2026-schedule.json` | JSON | Developers, apps, websites, data tools |
| `world-cup-2026-schedule.csv` | CSV | Excel, Google Sheets, databases |
| `world-cup-2026-schedule.ics` | ICS | Apple Calendar, Outlook, Google Calendar-compatible imports |

## Dataset coverage

The dataset includes:

- 104 total match slots
- 72 group-stage fixtures
- 32 knockout-stage placeholders
- Match number, stage, group, date, time, teams, venue, city, country, status, and source fields

Knockout-stage placeholders will be updated as teams qualify during the tournament.
